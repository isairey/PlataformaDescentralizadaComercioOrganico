# 🌌 Acerca del proyecto

**Dvilla Local Food Store** es una plataforma descentralizada de e-commerce diseñada para la compra y venta de alimentos orgánicos y productos saludables utilizando blockchain y smart contracts sobre Stellar.

El sistema permite:

- 🛒 Comprar productos orgánicos
- 🍎 Gestionar alimentos saludables
- 👤 Registro de usuarios
- 💰 Recompensas para clientes frecuentes
- 🌐 Transacciones blockchain
- ⚡ Integración Web3
- 🔒 Seguridad descentralizada

La plataforma fue desarrollada con enfoque en:

- 🌱 Vida saludable
- 🌐 Comercio descentralizado
- ⚡ Experiencia moderna
- 🔐 Seguridad blockchain
- 🚀 Escalabilidad
- 📱 Compatibilidad multiplataforma

# 🚀 Configuración del proyecto

```bash

```

---

## 2️⃣ Entrar al proyecto

```bash
cd PlataformaDescentralizadaComercioOrganico
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Ejecutar aplicación

```bash
npm run dev
```

---

## 5️⃣ Abrir aplicación

```bash
http://localhost:3000
```

---

# 🦀 Deploy del Smart Contract

## 📦 Instalar contrato

```bash
stellar contract install \
--network testnet \
--source token-admin \
--wasm target/wasm32-unknown-unknown/release/stellar_localfoodstore_contract.wasm
```

---

## 🚀 Deploy del contrato

```bash
stellar contract deploy \
--wasm-hash <WASM_HASH> \
--source token-admin \
--network testnet
```

---
